# Locking down VPC traffic with security groups, NACLs and Session Manager

- **Date:** 2026-11-10
- **Topic:** Cloud Security
- **Source:** AWS Academy Learner Lab (Cloud Security), Lab 4.1 "Securing VPC Resources by Using Security Groups"
- **Time spent:** 90 min

## What I learned

- A subnet is public if its route table sends internet traffic to an internet gateway. A private subnet sends it to a NAT gateway, so its servers can reach out but nobody can reach in.
- Security groups are stateful firewalls on each instance. They only have allow rules. Allowing a whole security group as the source is better than listing IPs, because new servers get access just by joining that group.
- Network ACLs work at the subnet level. They are stateless, can deny traffic, and are checked lowest rule number first. Traffic has to pass both the NACL and the security group.
- A bastion host lets you SSH into a private server. With SSH agent forwarding, the private key never has to be stored on the bastion.
- Session Manager gets you a shell on a private server with no open SSH port and no bastion. Access is controlled through IAM and the sessions can be logged.

## Commands, queries or snippets

```bash
Least privilege for an app server: allow port 80 only from the proxy security group, not 0.0.0.0/0
Single-host source: use the private IP with /32
Bastion: ssh with -A (agent forwarding) to the bastion, then ssh to the private IP
```

## Why it matters for security

Rules like "0.0.0.0/0 on port 80/22" are some of the most common cloud misconfigurations and give attackers a direct way in. Keeping servers in private subnets, using security group references, and using Session Manager instead of open SSH shrinks the attack surface and leaves an audit trail.

## Questions / next step

- Agent forwarding still has a risk: someone with root on the bastion could use the forwarded agent while I'm connected. Look into SSH ProxyJump as the safer option.
- Practice writing NACL rules that include the return-traffic (ephemeral) ports, since NACLs are stateless.
